Montaje rehecho con HyperFrames: fotografías a todo el ancho, fachadas a pantalla completa, tipografía cinética, transición de lamas, pases en planos con profundidad y transformación al render final. Cierre de siete segundos, sin contactos. Paleta marfil, carbón y oro apagado; tipografía Manrope.

Imágenes originales conservadas. Música y efectos compuestos para el montaje. Las imágenes de proceso se denominan modelo base y pases, sin atribuirles nombres técnicos no confirmados. El movimiento 3D corresponde a planos gráficos; no se reconstruye una órbita del edificio desde los JPG.

La imagen y el archivo se revisaron; el audio se verificó por medición, sin escucha manual. El ZIP contiene el mismo MP4, sin pérdida adicional de calidad.
